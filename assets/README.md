# University branding

`dit-logo.png` is a format conversion of the unmodified official asset downloaded
from https://www.dituniversity.edu.in/uploads/logos/dit_main.webp on 15 November 2026.
The university's media-kit page links to this asset:
https://www.dituniversity.edu.in/media-kits/logo .

The logo is used solely to identify the university in this academic project.
